Sourcier is built for diagnostics-heavy tools — compilers, linters, formatters,
language servers and code editors — that need positions which are cheap to
build, compare, store and serialize, yet still resolve back to the exact bytes
of the file they point at. Instead of dragging `String` paths and four `usize`
fields through every diagnostic, you pack the whole span into one `u64` and
keep the heavy data in a single immutable registry.

## Highlights

- **One `u64` per span.** File id, start line, start column, end line and end
  column are bit-packed together. Positions are `Copy`, cache-friendly, order
  naturally as integers and survive serialization round trips bit-exactly.
- **Constant-time lookups.** After finalization, path to id, id to path and id
  to content are all O(1); line and column navigation is O(log n).
- **Byte-accurate views.** With the default `view` feature, a position resolves
  to the exact bytes it covers, including multi-line spans and line terminators.
- **No unsafe code.** The whole workspace is `#![forbid(unsafe_code)]`, error
  enums are `#[non_exhaustive]`, and the `FileId` trait is sealed.
